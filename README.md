# Telemetria API - AgTech

API RESTful desenvolvida com Spring Boot e Java para gerenciamento de equipamentos e manutenções de telemetria agrícola.

## 🛠️ Tecnologias Utilizadas
- Java 17+
- Spring Boot 3
- Spring Data JPA
- PostgreSQL
- Bean Validation
- Swagger / OpenAPI
